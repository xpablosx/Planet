## 📖 Como usar:

### Buscar Planetas
1. Digite o nome de um planeta (ex: "Marte", "Júpiter")
2. Ou digite uma característica (ex: "vermelho", "anéis", "maior")
3. Clique em "Pesquisar" ou pressione Enter
4. Use "Limpar" para resetar a busca

### Foto Astronômica da NASA
1. Selecione uma data de nascimento (ou qualquer data após 16/06/1995)
2. Clique em "Buscar Foto da NASA"
3. Veja a foto astronômica daquele dia com explicação completa

## 🛠️ Como executar localmente:

1. **Abra o arquivo `index.html`** em qualquer navegador moderno
2. **Ou use um servidor local** para melhor experiência:
   ```bash
   # Com Python 3
   python -m http.server 8000
   
   # Com Node.js (se tiver o http-server instalado)
   npx http-server
   ```
3. Acesse `http://localhost:8000` no navegador

## 🔑 Sobre a API da NASA:

O site usa a **DEMO_KEY** da NASA que tem limitações:
- 30 requisições por hora por IP
- 50 requisições por dia por IP

Para uso intensivo, obtenha uma chave gratuita em: https://api.nasa.gov/

Depois substitua a variável `NASA_API_KEY` no arquivo `app.js`.
